# RUTOVA AI Website

Official starter website for RUTOVA AI — AI, Automation, Websites, Cloud & IT Solutions.

## GitHub Pages
Upload all files to a public GitHub repository named `rutova-ai`, then enable:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Before publishing
- Replace `hello@rutovaai.com` with your actual business email.
- Verify the WhatsApp Business short link.
- Add the final RUTOVA AI logo under `assets/` if desired.
